# 棋理 · 中国象棋 AI 教练

一个面向中国象棋初中级玩家的 Web 教练原型。目标不是复制天天象棋或 chess.com，而是解释每一步为什么好、为什么有问题，以及下次应该检查什么。

## 当前功能

- 标准中国象棋棋盘与基础合法走子
- 用户执红与电脑对弈
- 三档电脑难度
- 实时教练解释开关
- 候选着、棋盘事实和训练原则
- 着法记录、悔棋、重新开始、翻转棋盘
- 导入复盘入口占位

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

## 当前限制

- 电脑棋力使用本地启发式和浅层搜索，不是 Pikafish。
- 教练解释基于可验证的基础棋盘事实，但仍属于产品原型。
- 尚未支持长将、长捉、重复局面等完整比赛规则。
- 尚未支持棋谱导入、用户账户和云端保存。
